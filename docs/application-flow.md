# Application Flow

The application flow shows the main user journey through the *Beat the Scammer* prototype. Users move through a simulated scam call, select responses, receive feedback, and complete a reflection activity before receiving prevention advice.

![application flow diagram](../client/assets/images/application-flow.png)

# Flow Description

**Home Screen**

The user starts the training activity from the home screen.

**Instructions**
The user receives instructions explaining the purpose of the activity and how to interact with the simulated call.

**Incoming Scam Call**
The application displays an incoming call screen to simulate receiving a suspicious phone call.

**Scenario / Conversation**
The user follows a simulated conversation with the caller. Mock or pre-recorded audio may be used to represent the caller.

**User Response**
The user selects a response using an on-screen button. The response determines whether the user follows a safe or unsafe response path.

**Safe / Unsafe Response Path**
The selected response leads to the corresponding path and demonstrates the possible consequences of the user's decision.

**Feedback**
The application explains whether the selected response was appropriate and provides information about the scam.

**Reflection**
The user is asked to decide whether the caller was an AI voice or a real person.

**AI Voice / Real Person**
Both reflection choices lead to an explanation and reveal of the correct answer.

**Explanation / Reveal**
The application explains the correct answer and highlights relevant signs or behaviours that the user should consider in a similar situation.

**Prevention Tips**
The user receives practical advice for recognising and responding to AI voice impersonation scams.

**End**
The training activity finishes after the prevention information has been presented.
